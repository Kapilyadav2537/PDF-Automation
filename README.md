# PDF Modification & Automation Tool

An intelligent PDF modification system with predefined core skills and Google Gemini AI model integration.

---

## 🚀 Step 1: Predefined Skills Set (Testing & Core Tools)

The system includes a modular `SkillRegistry` with PDF modification skills implemented in [`skills/pdf_skills.py`](skills/pdf_skills.py). It is the single source of truth for both the Gemini CLI (`main.py`) and the Claude agent (`pdf_agent.py`):

| Skill Name | Description | Key Parameters |
| :--- | :--- | :--- |
| **`extract_text`** | Extracts plain text from all pages or a subset of pages (optionally to a `.txt`). | `input_pdf_path`, `pages`, `output_txt_path` |
| **`rotate_pages`** | Rotates specific or all pages clockwise (90°, 180°, 270°). | `input_pdf_path`, `output_pdf_path`, `rotation_angle`, `pages` |
| **`merge_pdfs`** | Merges multiple PDF files into one output document in order. | `input_pdf_paths` (list), `output_pdf_path` |
| **`split_pdf`** | Extracts specific page ranges (e.g., `'1-3, 5'`, `'7-'`) into a new PDF. | `input_pdf_path`, `output_pdf_path`, `page_range` |
| **`split_pdf_into_parts`** | Splits a PDF into files of N pages each. | `input_pdf_path`, `output_pdf_path`, `pages_per_file` |
| **`add_watermark`**| Stamps a semi-transparent text watermark across PDF pages. | `input_pdf_path`, `output_pdf_path`, `watermark_text`, `pages`, `opacity` |
| **`delete_pages`** | Deletes specific 1-indexed pages from a document. | `input_pdf_path`, `output_pdf_path`, `pages_to_delete` |
| **`encrypt_pdf`** | Password-protects a PDF (AES-256). | `input_pdf_path`, `output_pdf_path`, `user_password`, `owner_password` |
| **`decrypt_pdf`** | Removes password protection (requires the password). | `input_pdf_path`, `output_pdf_path`, `password` |
| **`pdf_info`** | Reports page count, page size and metadata. | `input_pdf_path` |
| **`clarify`** | Asks the user a question instead of guessing missing values. | `question` |

Page parameters accept a list (`[1, 3]`) or a spec string (`'1-3,5,7-'`, `'all'`), parsed by the shared helper in [`skills/pages.py`](skills/pages.py). Every reading skill accepts an optional `password` for encrypted inputs. Both backends execute skills through the sandbox in [`skills/sandbox.py`](skills/sandbox.py): inputs must live in the working directory (`testpdfs/` for `main.py`) or the output directory, and outputs are confined to `output/`.

Each skill is registered using the `@registry.register` decorator, which automatically introspects function signatures and generates OpenAPI/JSON-Schema specifications for Gemini.

## 🔐 Step 2: Loading Gemini Model from a Secret File

Your Gemini API key is kept strictly private and safe from inspection:

1. **Secret File Location**: Stored in a `.env` file in the root directory.
2. **Git Ignored**: `.env` and `*.secret` are listed in `.gitignore` to prevent committing secrets.
3. **Unreadable for AI Assistant**: The assistant will **never** read or inspect your `.env` file directly. Python's `python-dotenv` loads the key directly into memory at runtime.

### Setup Instructions for Secret File:

1. Copy the provided `.env.example` template to `.env`:
   ```bash
   cp .env.example .env
   ```
2. Open `.env` in your text editor and paste your API key:
   ```env
   GEMINI_API_KEY=AIzaSy...your_actual_key_here
   GEMINI_MODEL_NAME=gemini-3.8-flash
   ```

## 📦 Installation & Setup

1. Install the required Python dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the interactive assistant:
   ```bash
   python3 main.py
   ```
   - Automatically scans `testpdfs/` and previous results in `output/`.
   - Allows selecting target PDF(s) by number or typing `L` for the latest generated file.
   - Accepts your natural language modification prompt.
   - Shows matching skills and exact parameters (or explains if no skill exists).
   - Asks for confirmation before executing and saving to `output/`.

3. Run automated tests across all 6 skills and model connection:
   ```bash
   python3 test_skills.py
   ```

4. Or pass a one-line prompt directly via CLI:
   ```bash
   python3 main.py --prompt "Rotate page 1 of CS201Marks.pdf by 90 degrees and add CONFIDENTIAL watermark"
   ```
